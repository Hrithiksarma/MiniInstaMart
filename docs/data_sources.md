# Data sources

Everything used so far is **synthetic**, generated by `src/simulator/orders.py` from `config.yaml` (seed 42).

## Public datasets (planned, not downloaded yet)

| Dataset | Intended use | Status |
|---|---|---|
| Instacart Market Basket (Kaggle) | realistic product catalogue and baskets for Module A | not downloaded; licence and terms to be verified before use |
| Amazon ESCI shopping queries | realistic search queries and relevance labels for Module A | not downloaded; licence to be verified |
| A Kaggle food-delivery dataset | sanity check of real delivery-time distributions for Module B | not chosen yet; licence to be verified |

Downloads need Kaggle credentials and are not needed before Phase 6. If a dataset is unavailable or its terms do not allow our use, Module A falls back to a simulated catalogue and queries (the architecture does not change).

All results in this repository must be described as coming from synthetic or public data.
