# Mini Instamart ML Platform

A small quick-commerce ML platform: dynamic search filters, delivery-time (ETA) estimation with calibrated quantiles, and an A/B testing toolkit, plus serving and monitoring.

All data is public or synthetic. Nothing here claims production or Swiggy-scale results.


## Quick start

```bash
python -m venv .venv
.venv/Scripts/activate        # Windows; use source .venv/bin/activate elsewhere
make install
make test
```
